# Bayesian Statistics

This repository contains coursework, exercises, and assignments for the Bayesian Statistics lecture.

## Getting Started

### 1. Prerequisites

Make sure the following software is installed:

- [R](https://www.r-project.org/)
- [RStudio](https://posit.co/download/rstudio-desktop/)
- [Git](https://git-scm.com/)

### 2. Clone the Repository

Open RStudio and navigate to:

**File → New Project → Version Control → Git**

Paste the HTTPS URL of this GitHub repository into the *Repository URL* field.

Choose a local directory and click **Create Project**.

RStudio will clone the repository and open it as an RStudio project.

Alternatively, clone the repository using the terminal:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Then open the `.Rproj` file in RStudio.

### 3. Working with the Repository

Open the RStudio project using the `.Rproj` file.

To save and upload changes to GitHub, use the Git tab in RStudio or run:

```bash
git add .
git commit -m "Update coursework"
git push
```

To retrieve the latest changes:

```bash
git pull
```
